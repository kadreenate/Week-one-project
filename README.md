# Week-I-project
How to implement least privilege principle on AWS
Step 1: Create an S3 bucket on AWS. To do this, follow these steps: Log in to the AWS Management Console > search for S3; click "Create bucket", add a globally unique name, leave all default settings as is and click "Create bucket". That gives us this: 

<img width="3419" height="668" alt="image" src="https://github.com/user-attachments/assets/cd508067-ba70-4584-992e-81e404a7abba" />

Step 2: Create a Custom Least-Privilege IAM Policy by searching for "IAM" on the search bar > click on "Policies on the left-hand side of the IAM page" > "Create policy." Paste this JSON command under the JSON tab: 
{
"Version": "2012-10-17",
"Statement": [
{
"Sid": "AllowListingDevBucket",
"Effect": "Allow",
"Action": [
"s3:ListBucket"
],
"Resource": "arn:aws:s3:::cloud-dev-bucket-na"
},
{
"Sid": "AllowReadingAndWritingFilesInDevBucket",
"Effect": "Allow",
"Action": [
"s3:GetObject",
"s3:PutObject"
],
"Resource": "arn:aws:s3:::cloud-dev-bucket-na"
}
]
}
WARNING: Replace your unique S3 bucket name in the JSON command; otherwise, it won't work.

To update the user's permissions to perform more actions, use this JSON file:

{
	"Version": "2012-10-17",
	"Statement": [
		{
			"Sid": "VisualEditor0",
			"Effect": "Allow",
			"Action": [
				"s3:ListAllMyBuckets",
				"s3:GetBucketLocation",
				"s3:GetObject",
				"s3:PutObject"
			],
			"Resource": "*"
		},
		{
			"Sid": "VisualEditor1",
			"Effect": "Allow",
			"Action": "s3:ListBucket",
			"Resource": "arn:aws:s3:::cloud-dev-bucket-na"
		},
		{
			"Sid": "VisualEditor2",
			"Effect": "Allow",
			"Action": [
				"s3:PutObject",
				"s3:GetObject",
				"s3:ListBucket",
				"s3:GetBucketPolicy"
			],
			"Resource": "arn:aws:s3:::cloud-dev-bucket-na"
		}
	]
}

To update the JSON command, do this: go to "Policies" > search the policy you created earlier ("iam-policy-configuration" in this case), click "edit", and update the JSON in the policy editor and save the changes.
